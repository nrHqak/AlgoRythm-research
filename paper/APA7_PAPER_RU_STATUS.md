## 3. Первичный вывод

**Предзарегистрированная гипотеза H1 не подтверждена.** Специфичная для
алгоритмического паттерна структурная подсказка (условие C) не улучшила точность
локализации Top-1 по сравнению с согласованной универсальной отладочной подсказкой
(условие B): 12/30 (40.00%) против 12/30 (40.00%), разница 0.00 п.п., точный
критерий Макнемара *p* = 1.0, *b* = 3, *c* = 3, *d* = 6, бутстреп 95% ДИ
[−16.67; +16.67] п.п. Шлюз нулевого контроля пройден (*d*<sub>null</sub> = 5 <
*d*<sub>primary</sub> = 6), с минимальным запасом.

Результат квалифицирован в статье как **нулевой/смешанный калибровочный
результат, а не как несостоявшееся исследование**, и явно **не** как
доказательство эквивалентности условий.

## 5. Ограничения, добавленные по итогам фактических данных

1. **Нулевой результат не является проверкой эквивалентности** — процедура
   equivalence testing не предзарегистрирована, не проводилась и не может быть
   подставлена задним числом.
2. **Эмпирический «пол шума» сопоставим с сигналом** — *d*<sub>null</sub> = 5
   против *d*<sub>primary</sub> = 6; шлюз пройден с минимальным запасом.
3. **Отсутствие детерминизма при температуре 0** — 0.00% ячеек с побайтово
   идентичными пятью ответами во всех четырёх плечах; совпадение исходов Top-1
   по пяти повторениям лишь в 56.67–73.33% ячеек.
4. **Пилот не смог решить собственную задачу расчёта объёма выборки** — при
   ψ = 0.500 аппроксимация Макнемара вырождается; зарегистрированный статус
   «PILOT COULD NOT SIZE THE STUDY», диапазон *N* не определён.
5. **Взаимозависимость вторичных показателей** — Top-3, Top-5 и EXAM\*
   вычисляются по одному ранжированию и не являются тремя независимыми
   свидетельствами.
6. **Вынужденное ограничение усилия рассуждения** (`low`) — конфигурационное
   ограничение; поведение модели при более высоком усилии рассуждения в данной
   конфигурации недостижимо и потому не проверено.

Ранее зафиксированные ограничения (n = 30, смещение «только консенсус», два
аннотатора-модели вместо экспертов-людей, исключение 50 программ разногласия,
один язык, репрезентативность ConDefects, однострочный фильтр, исключение
условия задачи, отсутствие базовых SBFL/MBFL, отсутствие испытуемых-людей,
возможная контаминация, ограничения таксономии, асимметрия тега-разделителя)
сохранены и по-прежнему актуальны.
